# Image OCR Compatibility

| Item | Support |
|------|---------|
| Python | 3.10+ (per `pyproject.toml`) |
| OS | Windows, Linux, macOS (module-specific native deps may vary) |
| PyPI extra | `image or image-ocr` |
| Input | Image files or directories |

Test your target input versions in CI with fixtures under `image-to-md/tests`.
