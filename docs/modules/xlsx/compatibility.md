# Excel and CSV Compatibility

| Item | Support |
|------|---------|
| Python | 3.10+ (per `pyproject.toml`) |
| OS | Windows, Linux, macOS (module-specific native deps may vary) |
| PyPI extra | `xlsx` |
| Input | XLSX, XLSM, CSV |

Test your target input versions in CI with fixtures under `xlsx-to-md/tests`.
