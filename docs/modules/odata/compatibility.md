# OData Metadata Compatibility

| Item | Support |
|------|---------|
| Python | 3.10+ (per `pyproject.toml`) |
| OS | Windows, Linux, macOS (module-specific native deps may vary) |
| PyPI extra | `odata` |
| Input | OData CSDL metadata (XML/JSON), folders, ZIP archives, or $metadata URLs |

Test your target input versions in CI with fixtures under `odata-to-md/tests`.
