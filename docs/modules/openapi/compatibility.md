# OpenAPI Compatibility

| Item | Support |
|------|---------|
| Python | 3.10+ (per `pyproject.toml`) |
| OS | Windows, Linux, macOS (module-specific native deps may vary) |
| PyPI extra | `openapi` |
| Input | OpenAPI 3.x or Swagger 2.0 |

Test your target input versions in CI with fixtures under `openapi-to-md/tests`.
