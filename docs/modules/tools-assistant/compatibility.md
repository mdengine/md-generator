# AI Assistant Tools Compatibility

| Item | Support |
|------|---------|
| Python | 3.10+ (per `pyproject.toml`) |
| OS | Windows, Linux, macOS (module-specific native deps may vary) |
| PyPI extra | `skill-openai or skill-rag-chroma` |
| Input | Skill bundles and prompts |

Test your target input versions in CI with fixtures under `tool-assistant/tests`.
