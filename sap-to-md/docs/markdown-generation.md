# Markdown generation

Each SAP object receives a 12-section entity document:

1. Entity Summary
2. Business Meaning
3. Technical Metadata
4. Relationships
5. Validation Rules
6. Authorization Rules
7. Lineage
8. Dependencies
9. APIs
10. Related Tables
11. Related CDS Views
12. AI Semantic Tags

Split output under `entities/`, `technical/`, `functional/`, plus feature-specific folders.
